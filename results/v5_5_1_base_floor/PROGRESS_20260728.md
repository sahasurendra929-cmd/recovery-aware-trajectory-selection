## Scope and disconnect behavior

This controller contained only the V5.5.1 base diagnostic evaluation phase.
It did not contain Stage C, D, or E. It also did not perform training or data
generation. Stage C-E remain science-gated coordinator actions: they can only
start after a preregistered V5.5.x revision reaches its continuation gate and
the evidence is audited and pushed.

If the local network, SSH, or Codex session disconnected while the controller
was active, the controller, four vLLM services, three active shard evaluators,
and detached watchers continued. Git commits, GitHub push/read-back,
scientific gate interpretation, and dispatch of a later revision or stage
paused until connectivity returned.

If the RunPod container itself stopped, all processes stopped. Recovery must
inspect each `run_contract.json`, verify its registered SHA-256 values, keep
every incomplete directory as failure evidence, and launch only missing
batches from the exact frozen source. No completed batch may be overwritten.
